# Student Performance Analytics System

## Project Overview
The Student Performance Analytics System is a Python-based project developed to analyze student marks and attendance. It uses Pandas and NumPy to process student data and display meaningful information about academic performance.

## Objective
The main objective of this project is to simplify the analysis of student performance by calculating total marks, average marks, grades, and pass/fail results. It also helps identify top-performing students and compare performance across different subjects.

## Technologies Used
- Python
- NumPy
- Pandas
- CSV Dataset

## Features
- Reads student details from a CSV file.
- Calculates total and average marks for each student.
- Assigns grades based on average marks.
- Identifies pass and fail students.
- Finds the highest and lowest student averages.
- Identifies top-performing students.
- Calculates subject-wise average marks.
- Analyzes student attendance.
- Saves the analyzed results into a CSV file.

## Working
The system reads student information from a CSV dataset using Pandas. It processes the marks using Python functions, conditions, loops, and NumPy calculations. Based on the calculated averages and subject marks, it assigns grades and determines whether each student has passed or failed. Finally, it displays the overall class performance, subject-wise averages, top performers, and attendance details.

## Conclusion
This project demonstrates how Python, NumPy, and Pandas can be used for basic data analysis. It provides a simple way to understand student academic performance, reduces manual calculations, and presents useful information for evaluating marks and attendance.
